# Pump V5

Чистая переписка Pump-системы строго по методу (ТЗ `docs/TZ.md`).
V4 отошёл от метода (статистические прокси вместо правил) и давал минус IRL —
V5 возвращает систему к задуманному образу.

## Метод (канон)

- **Накопление:** цена в диапазоне до ~50% не менее **45 дней** (боковик или нисходящий тренд).
- **Канал:** боковик → плоские границы (max-high / min-low); нисходящий → наклонные.
- **Spark** (1 балл): одиночная зелёная свеча, объём которой больше **каждой** из ≤4 предыдущих красных по отдельности; маленькое тело (низкий price-impact).
- **Twix** (0.5 балла): спарк + приклеенная зелёная свеча; объём берём максимальный из пары.
- **Сигнал манипуляции:** сумма баллов **≥ 3**. Нисходящий→боковик — усиленный сигнал.
- **Вход:** пробой верхней границы на **4ч/1ч** + закрепление телом свечи. Пропуск если цена улетела >~10% (ATR-адаптивно).
- **Цель пампа (VAH):** верхняя зона объёмов fixed-range volume profile (пред-хай → текущая).
- **Выход:** трейлинг ~5% (ATR-адаптивный); если достигли VAH — выходим.
- **Стопы:** сингл → пред-лой канала; мартингейл → выход вниз из канала. Риск-менеджмент **≥ 3:1**.
