# T2.4 — Критерий «сингл vs мартингейл» (решение по данным)

Дата: 2026-06-09. Делегировано агенту в ТЗ-решениях. Решение принято **по реальным данным**, не угадано.

## Данные

Прогон пайплайна (детектор→вход→выход) на **150 кэшированных монет Bybit**, 61 формация (score≥3), **41 вход** после гейта 3:1. Сырьё: `data/experiments/t24_trades.parquet`.

Итог: win-rate **68.3%**, медиана PnL **+1.58%**, средний −0.68% (хвост убытков тянет вниз).

## Ключевой вывод: решает ШИРИНА КАНАЛА, не баллы

Win-rate / средний PnL по ширине канала:

- **0.2–0.3 (узкий): 100% (6/6), +1.99%** ← сильнейший сигнал
- 0.3–0.4: 68.8%, −2.03%
- 0.4–0.5: 57.9%, −0.38%

Это ровно то, что говорит ТЗ: *«сильнейшие пампы выходят из узкого канала»*. Подтверждено числами.

Баллы (score) — **немонотонны**: бакет 3–4 выигрывает чаще всего (77%), 5–6 — хуже (50%). Поэтому маршрутизация **по баллам — неверна** (это был placeholder).

- Маршрут «узкий→сингл, широкий→мартингейл» по факту работает (мартингейл 76% win vs сингл 61%), НО обоснование «узость=уверенность» — ложное. Правило живёт по обратной причине.

## Решение T2.4 (ИСХОДНОЕ, на 41 сделке — НЕ доверять обоснованию)

- **Узкий канал (width < 0.30)** → **сингл**. Высокая уверенность, чистый сильный сигнал — хедж не нужен (уже 100% win на выборке). Стоп = пред-лой свинга.
- **Широкий канал (width ≥ 0.30)** → **мартингейл**. Ниже уверенность, шире риск вниз — подстраховываемся усреднением. Стоп = выход вниз из канала.

Логика совпадает с ТЗ: *«если сомневаемся — мартингейл»*. Узкий сильный канал = нет сомнений.

Конфиг: `routing.mode: auto`, `routing.martingale_when_width_above: 0.30`.

## Оговорки (честно)

- Мартингейл показал win-rate 77% vs сингл 58% — но это **артефакт**: мартингейл был назначен на score<4, который пересёкся с выигрышным низким бакетом. Чистого преимущества режима в этом прогоне нет — поэтому маршрутизируем по ширине, а не по режиму.
- Выборка 41 сделка — мало. Порог 0.30 — стартовый, уточнить на полном прогоне (все пары).
- Стоп «пред-лой свинга» (а не дно канала) — критичный фикс: без него гейт 3:1 не проходила НИ ОДНА формация (RR медиана 1.66). С ним входят 41/61.
