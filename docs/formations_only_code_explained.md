## ⚠️ Важный честный вывод

Это НЕ баг: детектор находит самое тугое ИСТОРИЧЕСКОЕ под-окно (где спред был узким), а ручной мерит фикс-окна, заканчивающиеся СЕГОДНЯ (где цена уже разъехалась). Значит **ширины код-детектора систематически оптимистичнее текущей реальности** — он оценивает канал в момент накопления, а не на сейчас.
